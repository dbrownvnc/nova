① AI 서버용 CPU 수요 폭발 — 재고 소진

인텔의 어닝 가이던스에서 가장 충격적인 내용은 AI 서버용 CPU 재고가 완전히 소진됐다는 사실입니다. 과거 장부에서 감가상각 처리해 두었던 재고까지 사라졌습니다. 엔비디아 GPU에 밀려 사양길을 걷던 CPU가 다시 주인공으로 복귀한 것입니다.

② 테슬라 어닝콜 — 일론 머스크의 AI5 칩 위탁

일론 머스크가 "AI5 칩을 만들겠다"고 선언했지만 실제 제조는 인텔이 담당하기로 했습니다. 반도체 팹 운영 노하우를 보유한 인텔이 조용히 수혜를 받은 것입니다. 트럼프 행정부의 미국 내 공장 증설 정책도 맞물렸습니다.

③ 멀티 에이전트 AI — GPU 8:1 → 4:1로 변화

GPU 8개 기준, 4:1 비율 → CPU 2개 필요

AI가 에이전틱(Agentic) 모델로 전환되면서 CPU 수요가 급증했습니다. 과거에는 GPU 8개당 CPU 1개 수준이었지만, 멀티 에이전트 AI(메타 AI는 에이전트 16개 동시 운용)에서는 4:1로 CPU 비중이 두 배로 늘었습니다. 복잡한 오케스트레이션 로직이 CPU에서 처리되기 때문입니다.

오케스트레이션(Orchestration)이란?
여러 AI 에이전트가 한꺼번에 일하며 결과를 검증·조율하는 과정. 이 복잡한 조율 연산이 CPU에서 이루어집니다. 로컬에서 AI를 돌리면 CPU 온도가 60~70도까지 올라가는 이유입니다.
